**LK Jam** is an independent research project developing a real-time interactive AI system for jam sessions based on the GRU model.

Yakun Liu served as principal researcher and led the project independently, with collaboration from Zhi Jin. The work covered engineering architecture design, GRU-based time-series model training, and MIDI dataset preprocessing.

Key work included:

- Designing and implementing the full system architecture.
- Training a GRU-based model for time-series musical generation.
- Preprocessing MIDI datasets for real-time interaction.
- Developing a Python/C hybrid architecture.
- Building a custom shared-memory mechanism with high-precision timeline synchronization to support stable real-time performance interaction.
