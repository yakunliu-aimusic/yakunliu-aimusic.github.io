This Ministry of Education Industry-University-Research Project explored VR live interactive remote dual-stage concert production through 5G and campus network integration.

Yakun Liu served as core researcher under the guidance of Senior Eng. Hai Luan.

Key work included:

- Designing the layout for dual-venue remote performance.
- Constructing the acoustic environment for immersive concert production.
- Authoring the project conclusion thesis.
- Contributing to a replicable technical workflow for cross-regional collaborative performance.

The project produced strong outcomes and led to an approved follow-up grant: **Data Security and Information Assurance for Cross-Regional Dual-Stage Concerts via Campus Network and 5G** (No. 250403601102843, October 2025 – October 2026). Yakun Liu continues as core researcher, contributing to security model architecture design.
